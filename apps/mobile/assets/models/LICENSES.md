# Lisensi model 3D

| File | Sumber | Lisensi |
|---|---|---|
| `honda_supra_x_125_fi_v1.glb` | "Honda Supra x 125" oleh **boiledfish.vvti**, https://sketchfab.com/3d-models/honda-supra-x-125-6d61abb3aa3a4161bda31ef783111015. Diubah oleh proyek PrimeGarage: orientasi sumbu, nama node (`part__`/`body__`), dan titik sentuh (hotspot) dengan skrip `apps/mobile/scripts/prepare-supra-model.mjs`. | [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Wajib mencantumkan kredit penulis; kredit tampil di bawah viewer 3D. |
| `underbone_v1.glb` | Dibuat secara prosedural oleh proyek PrimeGarage dengan skrip `apps/mobile/scripts/generate-underbone-model.mjs` (three.js). Bentuk umum motor bebek, tanpa logo atau merek dagang. Dipakai untuk motor bebek lain dan sebagai cadangan jika model spesifik gagal dimuat. | MIT, sama dengan repo ini |

Setiap model baru wajib dicatat di tabel ini beserta sumber dan lisensinya (docs/3D-VIEWER.md bagian 3.1).
Model dari pihak ketiga hanya boleh dipakai jika lisensinya mengizinkan distribusi di aplikasi (misalnya CC BY, CC0).
